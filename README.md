## 📐 แนวคิดการออกแบบ (Design Philosophy)
ถอดแบบความงามทางวิศวกรรมจาก **GRID.GUILD / BUILD WITH LOGIC**:
- **Swiss / Neo-Brutalist Technical Grid**: เส้นกริดพิมพ์เขียว คมชัด ทุกสัดส่วนมีระเบียบตามตรรกะวิศวกรรม
- **Modular Bento Architecture**: จัดหมวดหมู่อย่างเป็นสัดส่วน ดูทางการ เรียบร้อย และทันสมัย
- **Technical Elements**: กากบาทมุม (`+`), แถบสแลชเอียง (`/`), แถบสถิติข้อมูล, รหัสพิกัด
- **Interactive Sketchpad**: พื้นที่แคนวาสวาดภาพ/วงจรไฟฟ้าในตัว สะท้อนความสามารถพิเศษ "มีสมาธิจดจ่อสูง และชอบวาดรูป"

## 🛠️ ระบบจัดการและตกแต่งเว็บไซต์ (In-Place Live CMS)
เมื่อล็อกอินสำเร็จ แถบควบคุม **ADMIN PANEL** จะปรากฏขึ้น:
1. **In-Place Live Edit (แก้ไขสดบนหน้าเว็บ):**
   - กดปุ่ม **EDIT MODE**
   - สามารถคลิกที่ข้อความใดก็ได้บนหน้าเว็บ (เช่น ชื่อ, คำอธิบาย, ข้อมูลติดต่อ, สถิติ) แล้วพิมพ์แก้ไขได้ทันที
   - ระบบจะบันทึกข้อมูลอัตโนมัติลงใน **LocalStorage** ของเครื่อง
2. **การเพิ่ม / ลบ / แก้ไข รายวิชาและผลงาน:**
   - มีปุ่ม `[ + เพิ่มรายวิชาใหม่ ]` และ `[ + เพิ่มชิ้นงานในวิชา ]`
   - มีปุ่ม `[ + เพิ่มผลงานใหม่ ]` พร้อมเลือกหมวดหมู่ (ไฟฟ้า, การสอน, ศิลปะ)
   - มีปุ่ม `แก้ไข` และ `ลบ` ในการ์ดทุกใบ
3. **ระบบอัปโหลดไฟล์ทุกประเภท (Universal File Uploader):**
   - รองรับไฟล์ รูปภาพ, คลิปวิดีโอ (MP4), เอกสาร (PDF), ฟอนต์ (WOFF/TTF)
   - ข้อมูลไฟล์ขนาดใหญ่จะถูกจัดเก็บลงใน **IndexedDB** ของเบราว์เซอร์อย่างปลอดภัย ไม่จำกัดขนาด 5MB เหมือนเว็บทั่วไป
4. **ระบบเปลี่ยนโทนสีและเอฟเฟกต์ (Visual FX & Themes):**
   - **Blueprint Blue** (สีน้ำเงินพิมพ์เขียวทางการ สไตล์รูปตัวอย่าง)
   - **Monochrome** (มินิมอลขาว-ดำ เรียบหรู)
   - **Amber Industry** (สีส้มอำพัน สไตล์ช่างอุตสาหกรรม)
   - **Emerald Circuit** (สีเขียวแผงวงจรไฟฟ้า)
   - **Dark Navy** (โหมดกลางคืน สีกรมท่าวิศวกรรม)
   - เปิด/ปิด เส้นตาราง (Grid Lines), จุดกราฟิก (Dot Matrix), และเครื่องหมายมุม (`+`)
5. **การสำรองและย้ายข้อมูล (Export & Import JSON):**
   - กดปุ่ม **EXPORT** เพื่อดาวน์โหลดไฟล์ `.json` เก็บไว้เป็นแบ็กอัป
   - กดปุ่ม **IMPORT** เพื่อนำข้อมูลที่สำรองไว้มาแสดงผลในเครื่องอื่นได้ทันที
